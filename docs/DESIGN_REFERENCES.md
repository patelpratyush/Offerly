# Offerly workspace design references

Reviewed October 19, 2026. Public product pages and help documentation were used as references; no private competitor account was accessed and no competitor assets were copied into Offerly.

- [Simplify job tracker](https://simplify.jobs/job-application-tracker): public tracker illustration makes application stages visible next to roles. Offerly uses prominent current-stage counts and selectable stage shortcuts. Counts describe current state, not historical funnel conversion.
- [Teal dashboard guide](https://help.tealhq.com/en/articles/9524944-exploring-the-dashboard): sorting, status grouping, and stage shortcuts inform Offerly's shared filters, table/board toggle, and explicit sorting controls.
- [Huntr job tracker help](https://help.huntr.co/en/collections/10297189-job-tracker): connected job cards, activities, contacts, and documents inform Offerly's Overview / Activity / People & files detail sections.

## Visual direction

A focused personal workspace: forest navigation rail, off-white canvas, white panels, restrained pastel stage badges, and Manrope/DM Sans typography served locally. Stronger contrast separates navigation, content, and action. A deadline panel replaces decorative dashboard copy. Cards show response ownership and work arrangement without conflating either with stage.

## Interaction decisions

- Stage strip is a filter, not a claim about completed previous stages.
- Advanced filters expand on demand; table and board render the same filtered collection.
- Import has three explicit steps: choose file, match columns/date format, review row decisions. Unknown dates remain unknown.
- Duplicate review shows both applications, evidence, and a reversible archive action. It never silently merges histories.
- Application detail separates overview, immutable activity history, and people/files. Child event changes remain visible after links change.
- Assessment deadlines and completion are distinct. Status changes require explicit manual entry.
- Mobile retains horizontally scrollable stage and board controls while forms/dialogs reflow. Keyboard users can edit stages without dragging.

Test screenshots use synthetic companies and applications, not private user data.
