# Redesigned page screenshots

Captured from the running local app with a disposable synthetic account, using the real authenticated API. No private mailbox, production account, or private evaluation material was used. Samples include two distinct applications at one company, a pending manual review, an interview, an assessment, an overdue task, a contact, and two immutable document versions with version 1 recorded as submitted. These are test fixtures, not production quality evidence.

Desktop viewport: 1440 × 1000. Mobile viewport: 390 × 844. Main pages use full-page screenshots; application detail uses a viewport screenshot because the dialog scrolls independently. Captures use reduced motion.
